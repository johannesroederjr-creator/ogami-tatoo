# OGAMI TATTOO – Website

Statische One-Page-Website für Frank Coltan-Wagner (OGAMI TATTOO).

## Lokal ansehen

Doppelklick auf `index.html` – kein Build nötig.

## Live-Vorschau (GitHub Pages)

https://johannesroederjr-creator.github.io/ogami-tatoo/

## Änderungen auf GitHub pushen

Im Projektordner in der Konsole:

```bash
git add .
git commit -m "Kurze Beschreibung der Änderung"
git push
```

GitHub Pages aktualisiert sich nach dem Push automatisch (1–2 Minuten).

## Struktur

```
index.html          Startseite
cover-up.html       Cover-up-Unterseite
impressum.html      Impressum
datenschutz.html    Datenschutz
css/style.css       Stylesheet
js/main.js          Galerie, Lightbox, Navigation
images/             Bilder
fonts/              Schriften (lokal)
```
